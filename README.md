### Will using OmniPatch get my AI account banned?

OmniPatch modifies local client files and does not interact with account credentials or servers. While client-side changes are possible, direct account bans are not a typical outcome of local activation methods.

### Can OmniPatch be detected by anticomponent software?

As a tool that modifies other software's local files, OmniPatch may trigger heuristic detections by some anticomponent programs. It is often necessary to create an exclusion rule or temporarily disable protection during use.

### Do I need to run OmniPatch as administrator?

Yes, administrator privileges are required for OmniPatch to write the necessary configuration and license files to the protected application directories on your Windows system.

### Does OmniPatch work on macOS or Linux?

No, OmniPatch is a Windows-only desktop utility designed specifically for the Windows versions of the supported AI applications.

### What happens if an AI app updates after I've activated it?

A major update might revert local changes. Simply run the OmniPatch tool again to re-apply the activation, which is typically very quick.

### Is there a portable version that doesn't require installation?

Yes, OmniPatch is distributed as a single portable executable. No installation is required, just extract and run the patcher directly.

### Can I use OmniPatch to activate multiple computers?

Yes, the tool can be used on any Windows machine. However, activation is tied to local files on each individual device, so each computer must be patched separately.
